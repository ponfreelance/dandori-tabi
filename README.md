# 段取りたび（dandori-tabi）

**家族の制約を入れると、破綻する箇所が先に出る。**

既存の旅程ツールが「候補を出す（足し算）」のに対し、本ツールは
**「破綻を見つける（引き算）」**に振り切っています。

👉 **使う**: https://ponfreelance.github.io/dandori-tabi/web/
（オフラインで動きます。データは端末内に保存され、サーバーには何も送られません）

## 何が出るか

- **身長判定** … ○ / △ あと◯cm / ×（単独と付き添い同伴の2基準。当日は靴込みで計測）
- **衝突検出** … 時間指定・再入場不可 × 昼寝・食事
- **ムダ枠検出** … 券に誰も乗れない対象が入っていないか
- **回り順** … 時間指定・昼寝・退園の締切を固定点に置き、**区間ごとに「何件入らないか」**
  （歩く分を引いた残り／整理券が要るエリア／時間指定が強いる往復のムダ）
- **逆算** … 帰りの便・新幹線から当日の締切／旅行日から予約解禁日
- **単一障害点** … 予約で確保できず失敗すると旅程が壊れるもの＋代替経路と判断時刻

## 使い方

1. 家族を登録する（身長・年齢・昼寝の時間帯）
2. チケット・宿・便の控えを**そのまま貼る**（整形不要・部分入力で動く）
3. 破綻・回り順・逆算・予約カレンダーを見る（予算を入れると超過も破綻として出る）
4. 画像1枚に書き出して家族に共有する（金額は既定で非表示）

複数の旅行はタブで並行して計画できます（入力・判定・予算は旅行ごとに独立）。

詳しくは [docs/MANUAL.md](docs/MANUAL.md)。

## 検証状況

```
7歳 120cm → ○7 △1 ×2      122cm → ○8 △0 ×2  （あと2cmで1つ反転）
※身長制限は公式「利用基準」で検証済（2026-07-23）。単独122cm/同伴時は各下限の2値モデル
貼り付け3件 → 全件パース成功、アトラクション名 6/6 突合
※フィクスチャは実旅程の構造を保った加工値（日付・便名・施設名は架空）

回り順 09:00–11:30 ハリウッド→ミニオン→マリオ（徒歩9分）→ 待ち45分と置くと3件
※エリアの並びは環状の順序、徒歩分は公式マップからの概算（未実測・verifiedAt:null）
※待ち時間は推定しない。件数は「仮定値を置いたらいくつ入らないか」を出すためだけに使う
```

## 開発する

`web/index.html` はビルド生成物です。正は `src/` と `data/` にあります。

```
python -X utf8 scripts/build.py      # src/ + data/ を web/index.html に埋め込む
node tests/acceptance_test.mjs       # 受け入れテスト
```
