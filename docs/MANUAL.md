# マニュアル

## 基本の流れ

```
1. 家族を登録   （身長・年齢・昼寝の時間帯）
2. 予定を貼る   （チケット・宿・便の控えをそのまま）
3. 破綻を見る   （衝突・ムダ枠・境界・単一障害点）
4. 回り順を見る （固定点の隙間に何件入らないか）
5. 逆算を見る   （いつ何を予約するか）
6. 共有する     （画像1枚。金額は非表示）
```

複数の旅行はタブで切り替えます（下記 0.）。

## 0. 複数の旅行（タブ）

複数の旅行を計画しているときは、上部のタブで切り替えます。
「＋ 新しい旅行」で追加でき、そのとき今の旅行のメンバーをコピーできます。
入力・破綻検出・予算は**旅行ごとに独立**です。タブの×で削除できます（最後の1件は消せません）。

## 1. 家族の登録

**身長は正確に測ってください。** 1cmで乗れるものが変わります。

境界（あと数cm）と判定された場合、当日は**靴を履いた状態で計測される**ため、
厚めのソールで届く可能性があります。過度な期待は禁物ですが、準備で結果が変わります。

一度登録すれば次の旅行でも使えます。**2回目からは、ここで悩む必要がありません。**

## 2. 予定の貼り付け

チケットの購入画面や予約確認メールを、**整形せずそのまま**貼ってください。
日付の書式（`2026年9月20日` / `2026/09/20`）が混在していても構いません。

読み取れなかった項目は空欄のまま残ります。**部分的に埋まれば動きます。**
埋まらない項目は「未定」として扱われ、そのまま最後の「これから決めること」に流れます。

## 3. 破綻の読み方

| 表示 | 意味 | やること |
|---|---|---|
| ○ | 条件を満たす | — |
| △ あと◯cm | 境界 | 正確に採寸。靴を検討 |
| × | 届かない | 対象から外す。券選びに反映 |
| ! 衝突 | 時間帯が接触 | 提示された順序に組み替える |
| ! ムダ枠 | 券に誰も乗れない対象が含まれる | 子どもスイッチで消化するか、券を選び直す |
| ! 単一障害点 | 予約で確保できず、失敗すると旅程が壊れる | **代替経路と判断時刻を必ず確認** |
| ! 取消不可 | 買うと戻せないものが、未確定の予約より先にある | **取り消せるものから確定する**（下記） |
| ! 予算超過 | 判明している金額の合計が予算を超えた | 削減候補（**取消可能なものだけ**）から見直す |
| ! 区間不足 | その区間は移動だけで時間が足りない | 間のエリアを捨てて直行するか、時間指定を取り直す |
| ! 整理券 | エリア入場整理券が要る場所を券で押さえていない | 入園直後に取得を試す。**取れなかったときの回り先を先に決める** |
| i 往復のムダ | 時間指定の順序が園内の往復を強いている | 並び順に沿う時刻へ寄せられないか確認する |
| ! 避けられない | 通りたくないエリアを通らずに行けない | **その時間より前に出る**か、通る前提で支度する |
| ! 希望が入らない | 行きたい件数が、その区間に入る件数を超えた | **順位をつけて捨てる**／別の日へ回す |
| ! 戻れない | 昼寝等でパークを出るが、あとに予定が残っている | **パーク内で休む**／出るならそれを最後にする |
| i 回る先が無い | 時間はあるのに、その区間で回れるものがない | 再訪・ショー・食事に充てるか、早めに切り上げる |

### 予算（任意）

「旅行日と交通手段」の欄に予算を入れると、貼り付けた控えから読み取れた金額の合計が
予算を超えたときに破綻として表示されます。金額が読み取れていない項目は「未計上」と
明示されます（合計は下限値）。削減候補に**取消不可のものは出ません** — 削れないからです。
予算と金額は、プレゼン画像には出ません（金額非表示の原則どおり）。

### 取消不可と予約の順序

「今すぐ買え（変動価格）」が成立するのは**取り消せるとき**か**依存が固まっているとき**だけです。
パークチケットやエクスプレス・パスは原則キャンセル不可。宿や便がまだ確定していない段階で
先に買うと、依存が取れなかったとき費用が戻りません。
予約カレンダーの各行に取消条件（取消可／条件付き／不可／要確認）が表示されるので、
**取り消せるものから確定 → 取消不可のものは依存が固まり次第すぐ買う**、の順序を守ってください。

### 単一障害点について

「予約不要」は安心ではありません。**予約で確保できない**という意味です。
このマークが出た項目は、代替経路と「何時までに判断するか」がセットで表示されます。
当日はその時刻に状況を見て、無理そうなら代替に切り替えてください。

## 4. パーク内の回り順

**これはおすすめの候補を増やす欄ではありません。** 動かせないもの（時間指定・再入場不可の枠・
昼寝・帰りの便からの退園締切）を先に置き、**その隙間に何が入らないか**を出します。

```
09:00–11:30  ハリウッド → ミニオン → マリオ（徒歩9分）
             150分 − 徒歩9分 = 実質141分 → 待ち45分なら 3件（候補3件）
11:30–13:30  スーパー・ニンテンドー・ワールド（時間指定・再入場不可）
13:30–15:30  昼寝
```

- **開園・閉園** … 当日の時刻を入れてください。券に入場時間があれば開園はそこから入ります。
  帰りの便を貼ってある日は、**退園の締切（逆算値）が閉園より優先**されます。
- **待ち（仮定・分）** … 待ち時間は当日次第なので**推定しません**。
  「45分と置いたら何件入るか」を数えるためだけの仮定値です。実感に合わせて変えてください。
- **徒歩分** … 公式マップからの概算で、実測値ではありません（子連れはこれより遅くなります）。
- **エリアの順** … パークは環状なので、短いほうの向きを選びます。
  時間が余っていて、直行だと乗るものが尽きる区間だけ、遠回り（一周）に広げます。

判定マークは `○ 全員乗れる` / `△ 一部の子は乗れない（名前を併記）` / `◇ 子どもは全員×＝大人交代`。
**時間指定で乗るものは候補から外れます**（二重に数えないため）。

### 1.5デイ・2デイ券（2日に分ける）

券名に「1.5デイ」「2デイ」が入っていれば、**入場日＋翌日**の2日に自動で展開します。
控えに書いてあるのは入場日1つだけなので、ツール側で解釈しています。

- **1.5デイ** … 初日は**券の入場時間から**（例 15:00）、2日目は開園から終日
- 開園・閉園は**日ごとに**入れられます（日の見出しの右）
- **前の日に回るぶんは、翌日の候補から外します。** 入らなかったぶんは翌日へ残ります
  ＝これが「2日に分ける」の中身です
- どの日であれ**時間指定で乗るものは、他の日の候補に出しません**（二重に数えない）
- 行きたいものは**日をまたいで1回だけ判定**します（初日に入らなくても2日目に入るなら○）

```
1日目 2026-11-15（15:00〜21:00）1.5デイ・スタジオ・パス（1/2日目）
  15:30–21:00  ハリウッド→…→ハリウッド（徒歩39分）
               実質291分 → 待ち45分なら 6件（候補8件）
2日目 2026-11-16（09:00〜20:00）1.5デイ・スタジオ・パス（2/2日目）
  09:00–11:30  ハリウッド→ミニオン→マリオ（徒歩9分）→ 3件
  11:30–13:30  スーパー・ニンテンドー・ワールド（時間指定・再入場不可）
```

初日の入場前に終わる昼寝は「入園前」として扱い、**再入場の警告は出しません**
（パークを出た話ではないため）。パーク時間の外に完全に外れる予定は表示しません。

### 行きたいアトラクション

**指定できます。** ただし候補が増えるわけではありません。**「外せないもの」の宣言**として扱い、
入らないもの・通らないもの・乗れないものを1件ずつ確定させます。

| 表示 | 意味 | やること |
|---|---|---|
| 確保済み | 時間指定の枠で押さえている | — |
| 入ります | その区間の実質時間に収まる | — |
| 要選択 | 同じ区間の希望が入る件数を超えた | **順位をつけて捨てる**（どれが残るかツールは決めません） |
| 通りません | 今の回り順にそのエリアが入っていない | 「寄ると +◯分」が出るので、入るか判断する |
| 回れません | 避けたいエリア／全員×で対象外 | 避ける範囲を見直すか、行き先から外す |
| 乗れません | 身長が届く人がいない | 外す（境界なら02の判定を確認） |

- 行きたいものが**反対側にあるなら、遠回りしてでも通る向き**を選びます（希望が優先）。
  そのぶん歩く時間は増えるので、実質時間と件数はその前提で出ます
- 子どもが全員乗れないもの（例：132cm以上）は、**大人交代（子どもスイッチ）**として注意が出ます
- 希望は候補の**先頭に★付き**で並びます。上から順に取れば希望が残ります

### 通りたくないエリア（ゾンビなど）

避けたいエリアを選ぶと、**そこを通らない向きで回り順を組み直します**（パークは環状なので、
たいていは反対回りで避けられます）。時間帯を入れれば、その時間だけ通行止めとして扱います。

```
避けたい：ジュラシック（18:00〜）
17:30–18:00 ジョーズ（時間指定）
18:00–21:00 アミティ→ウォーターワールド→ハリポタ→マリオ→ミニオン→ハリウッド
            ＝ +9分の遠回りで避けています
```

**避けられない場合は「避けられない」と出します。** 黙って通る道を引きません。

- **出口は入口と同じエリア（ハリウッド）です。** ここを避けたい場合、閉園前に出るなら必ず通ります。
  「その時間より前に出る」か「通る前提で支度する（抱っこ・前を歩く・イヤーマフ）」の二択になります
- 避けたい時間帯に**時間指定の枠**が入っていれば、破綻として出します
- 避けた結果、**時間はあるのに回る先が無い区間**ができたらそれも出します
  （早めに切り上げる、という判断はここでしてください）

ハロウィーン期間など、**その日に出るもの**が分かっている場合は候補として提示します
（「ハリウッド・ニューヨーク・ジュラシックを避ける」ボタン）。ただし**避けるかどうかを決めるのは
利用者**で、ツールは勝手に避けません。出没エリアは年ごとに変わるため
`park-layout.usj.json` の `hazards` は**未検証（`verifiedAt: null`）**です。**当日の公式マップで
必ず確認してください。**

### 再入場（「2つの再入場」を混同しないこと）

このツールには**別物の「再入場」が2つ**出てきます。

| | 何の話か | 効いてくる場面 |
|---|---|---|
| **パークの再入場** | **券種**の話。USJは**年間パス以外は再入場できません**（一度出たらその日は戻れない） | 昼寝でホテルへ戻る／食事に出る |
| **エリアの再入場不可** | **整理券・時間指定枠**の話（例：スーパー・ニンテンドー・ワールド） | エリアを出ると同じ枠では戻れない |

昼寝には**場所**（パーク内で休む／一度パークを出る）を指定できます。
「一度出る」を選ぶと、**そのあとに予定が残っていれば破綻として出ます。**

```
! 13:30–15:30 にパークを出ると戻れません
  第3子(1歳)の昼寝のあとに 1件の予定（15:30–20:00の区間まで）が残っています。
  → パーク内で休む（ベビーカー・屋内の休憩スペース・レストラン）か、
    この休憩を最後にして以降の予定を捨てる。
```

例外（当日の運用で変わります・必ず現地で確認してください）:
混雑期（GW等）に一般ゲストも再入場できる日がある／学校団体は申込時の申請で可／
当日パーク内の年間パスセンターで年間パスへアップグレードすれば戻れます。

年間パスを持っている場合は、券名に「年間パス」が入っていれば再入場できる前提で組みます。

> **未検証：** 公式サイトはJS描画のため機械的に取得できず、`park-layout.usj.json` の
> `reentry` は `verifiedAt: null` です。**公式の最新情報で必ず確認してください。**

### 整理券（エリア入場）

スーパー・ニンテンドー・ワールドとハリー・ポッターエリアは、混雑時に**エリア入場整理券**が
必要になります。時間指定の券で押さえていない場合、**取れなければその区間はまるごと消えます**。
警告が出たら、取れなかったときに回る先を先に決めておいてください。

## 5. 予約カレンダー

**いま行動できるものが上**、あとは近い順に並びます。

- **▶ 受付中** … **もう予約できます。**解禁日を過ぎて窓が開いている状態。
  窓に終わりがあるもの（事前申込・1年前予約）は「締切まであと◯日」が出ます
- **時刻つき**（例 `10/15 10:00`）… その時刻ちょうどに操作する
- **今すぐ** … 締切はないが、待つほど高くなる／売り切れる
- **予約不要** … 予約制度がない（→ 単一障害点の確認へ）
- **監視中** … 解禁日が非公表。②を使うと自動で通知されます
- **締切** … 窓が閉じた（例：事前申込は発売開始日の朝で終わり → 通常発売へ）

**解禁日は「締切」ではなく「窓の開き」です。** 過ぎたものは失効ではなく受付中なので、
このツールは期限切れとして下に流しません（取り逃しの元になるため）。

### 新幹線は3つの窓があります（東海道・山陽／スマートEX）

| いつ | 何ができるか | 代償 |
|---|---|---|
| 乗車1年前 5:30 〜 1ヶ月前 7:30 | **1年前予約**。今すぐ席を確保できる | **座席を選べない**（1ヶ月前8:00以降に確定通知）。予約と同時に決済・払戻手数料あり。早特やS Work席は対象外 |
| 発売開始日の7日前 5:30 〜 当日 7:30 | **事前申込**。10時に張り付かなくてよい | 席番指定は不可。満席なら**不成立**（結果は当日8:00以降にメール） |
| 乗車1ヶ月前 10:00 〜 | **通常発売**。席番を選べる | 人気列車は10時で埋まる |

子ども連れで**並び席が必要なら、席を選べる10時の通常発売**と、先に確保できる1年前予約の
どちらを取るかを決めてください。両方は取れません（同じ席を二重に押さえることになります）。

## 6. 共有

画像を書き出してメッセージアプリで送れます。
**金額は既定で表示されません。** 表示したい場合は書き出し時に切り替えてください。

## カスタマイズ

### アトラクションを足す・直す
`data/attractions.usj.json` を編集します。
```json
{"id":"xxx","name":"正式名","short":"略称","area":"エリア","minHeight":107,"minHeightWithAdult":null}
```
`minHeight` が `null` は「制限なし」です。**不明な場合も `null` にせず、TODOコメントを残してください。**

### エリアの並び・徒歩分を直す
`data/park-layout.usj.json` を編集します。`ring` は**入口から一方向に並べた環状の順序**で、
`toNextMin` は「次のエリアまでの徒歩分」（最後の要素は先頭へ戻る分）です。
```json
{"area":"ミニオン","names":["ミニオン・パーク"],"toNextMin":4,"gate":true,"gateNote":"整理券が要る場合があります"}
```
- `names` … 券に出るエリア名（「スーパー・ニンテンドー・ワールド」など）を寄せるための別名。
  アトラクションではなくエリアの入場枠は、これでエリアに解決されます。
- `gate` … エリア入場整理券が要る場所。時間指定で押さえていないと警告が出ます
- `hazards` … その日に出るもの（ゾンビ等）の候補。`season` の期間内の日にだけ提示されます。
  `areas` は ring の `area` 名で書きます。**避けるかどうかは利用者が決めるので、ここは提案です**。
- `assumeWaitMin` … 待ちの仮定値の初期値（画面から変更できます）。**実測値ではありません。**
- `verifiedAt` … 実測して確かめたら日付を入れてください（`null` の間は画面に「概算」と出ます）。

### 別のパークを足す
`data/attractions.<park>.json` を追加します。エンジン側の変更は不要です。
回り順も使うなら `data/park-layout.<park>.json` を合わせて追加します（無ければ 04 は出ません）。

### 予約ルールを足す
`data/booking-rules.json` に追記します。`offsetMonths`（暦月）と `offsetDays`（日数）を
使い分けてください。「1ヶ月前」は必ず `offsetMonths: -1` です。

### 境界の閾値を変える
既定は5cm。`EDGE_CM` を変更してください。

## よくある質問

**Q. 身長を入れずに使えますか**
判定は出ません。身長がこのツールの起点です。

**Q. なぜ金額が資料に出ないのですか**
家族に見せる前提だからです。必要なら表示に切り替えられます。

**Q. 待ち時間はどこから取っていますか**
取っていません。当日の状況次第で、事前に当てられるものではないからです。
回り順の「待ち◯分」は**自分で置いた仮定値**で、区間に何件入らないかを数えるためだけに使います。

**Q. おすすめのアトラクションは出ませんか**
出しません。このツールは候補を足しません。**乗れるもののうち、時間に入らないものを削る**だけです。

**Q. 監視は何回まで動きますか**
1日1回なら年365回で、無料枠に収まります。頻度を上げすぎると制限がかかります。

**Q. LINEに通知できますか**
LINE Notify は終了済みです。Discord Webhook、メール、ntfy を使ってください。
